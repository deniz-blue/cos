# Privacy Policy for cos

**Last Updated: June 30, 2026**

**cos** is an offline, open-source mobile application. This application does not collect, store, or transmit any personal data.

### 1. Data Collection and Transmission

- **No Network Access:** The application operates entirely without external backend servers, cloud storage, or internet communication.
- **No Telemetry:** The application does not include any analytics, tracking SDKs, or third-party monitoring services.

### 2. Device Permissions and Data Storage

- **Camera Access:** The camera permission is utilized solely to scan QR codes within the application interface. Image and video data from the camera are processed strictly in real-time on-device and are never saved or transmitted.
- **Local Storage:** All created QR payloads and lists of scanned history are saved exclusively within the application's local device sandbox. This data can be permanently removed by deleting the application data or uninstalling the app.

### 3. Source Code Transparency

The complete source code for **cos** is publicly available for independent audit and verification at: **https://github.com/deniz-blue/cos**.
